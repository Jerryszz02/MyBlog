## 配置要集中

如果一个项目需要被反复维护，站点名、作者、链接和外部地址应该集中到一个配置文件里，而不是散落在页面中。

## 验证要可重复

第一版至少应该保留 lint、typecheck 和 build 三个检查。它们不能覆盖所有体验问题，但能快速发现结构性错误。

## 交接要能从零读起

规划文档和 README 应该面向零上下文读者，让下一位维护者知道项目为什么存在、由哪些部分组成、如何继续开发。
