## 目标

基于固定版本 DSH 扩展个人 Agent，将对话、记忆和长任务执行连接起来。提供本地 Web 界面与 CLI，主对话支持连续交流、取消和文件产物，运行数据与实验环境分别保存。

## 关键实现

- 用检查点、任务状态和动作回执支持跨会话恢复；副作用结果不明时先核验，避免重复执行。
- 以 SQLite 保存带来源、范围和有效期的记忆，删除来源后撤销相关证据；上下文有明确预算。
- 文件工具和命令受路径及 macOS 沙箱约束；运行器独立检查产物，并在模型请求前预留费用。
- 接入周期调度、通知队列和逐动作授权的邮件连接器，将提案、批准与执行回执持久化。

## 当前进展

最小真实模型任务与有界跨天提醒已有历史验收。当前服务和凭据检查暂停，真实邮件闭环、系统重启恢复及长期使用效果仍待验证。自动测试覆盖模拟模型与故障恢复；封面为隔离示例空间。
